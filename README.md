# FastSpeech 2 TTS (English & Telugu)

Implementation of FastSpeech 2 architecture with Feed-Forward Transformer blocks and custom Variance Adaptor for Duration, Pitch, and Energy prediction.

## Structure
- `English/`: Preprocessing, training, and inference scripts.
- `Telugu/`: Preprocessing, training, and inference scripts.
- `Results/`: Checkpoints, audio samples, and variance adaptor plots.
- `Report/`: Technical Report PDF.
